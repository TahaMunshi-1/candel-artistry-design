# Candle Artistry Design

```
frontend/   # Vite + React client
backend/    # API / server
```

## Frontend

```bash
cd frontend
npm install
npm run dev
```

Image processing helpers used for site assets live in `frontend/tools/` (not required to run the app).

## Deploy on Vercel

1. Import this repo in Vercel
2. Set **Root Directory** to `frontend`
3. Framework: Vite (uses `frontend/vercel.json`)
4. Deploy

## Backend

```bash
cd backend
npm install
npm run dev
```
